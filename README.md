One pickup line, spoken by a vending machine to a passing human — 84 characters, pure machine world: a slot code, a jammed coil, and a reason to come back and shake it again.

> Press B7 and I'll jam my own coil, just so you have to come back and shake me again.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is pure Python 3.13 standard library. It writes exactly the line above — nothing else, no trailing newline — to `/output/entry.txt`.
